# Jichu Li Academic Homepage

A self-contained static academic homepage based on [Minimal Light](https://github.com/yaoyao-liu/minimal-light).

## Maintain the site

- Edit `index.html` for profile, News, publications, and other content.
- Adjust `assets/css/custom.css` for personal layout overrides.
- Update the portrait and figures in `assets/img/`, the CV in `assets/files/`, and citations in `assets/bibtex/`.
- Fonts, icons, images, and styles are local. `.nojekyll` supports static hosting on GitHub Pages.

## Local preview

Run `python -m http.server 8771 --bind 127.0.0.1` from this directory and open <http://127.0.0.1:8771/>.
